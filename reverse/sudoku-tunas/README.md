## Flag

```
NEC{tunas_grows_through_constraints}
```

## Description

Sebuah permainan Sudoku sederhana telah tumbuh menjadi sesuatu yang sedikit berbeda.

Selesaikan puzzle yang tersedia dan perhatikan bagaimana aplikasi menentukan bahwa permainan benar-benar selesai. Tidak semua aturan yang digunakan terlihat dari papan permainan, dan jawaban yang benar mungkin menyimpan sesuatu yang lebih dari sekadar kemenangan.

Temukan apa yang disembunyikan oleh Sudoku Tunas. Flag Format: `NEC{...}`

File : `dst/sudokutunas.apk`
